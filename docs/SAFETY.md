# ファイル操作と Windows API の安全性

## 変更時の確認

- コピー・移動・置換の変更では、成功だけでなく途中キャンセル、確認後の宛先変更、スキップ、失敗時の復元を確認する。
- `app/src/shell.rs` の回帰テストは、一時ディレクトリの構造とファイルのバイト列を比較し、操作対象外への書き込みや削除も検出する。
- CI とリリースは rustfmt・Clippy（警告をエラー扱い）・単体テストを通す。Explorer との対話的な連携はローカルの `app/Check.ps1` で確認する。

## unsafe の前提

新しい `unsafe` では、ポインタの由来・有効範囲・寿命、所有権の移転、対応する解放方法、利用スレッドを確認する。重要な前提は呼び出し箇所の `SAFETY` コメントにも残す。

今回点検・補強した範囲：

| 境界 | 保持する条件 |
| --- | --- |
| OLE初期化 | `Apartment` は初期化成功時だけ生成し、同じスレッドで一度だけ `OleUninitialize`。`Send` / `Sync` を持たせない |
| クリップボード | `STGMEDIUM` の種別を確認してから union を読む。ロック成功と領域長を確認し、借用中はロックを保持。`ReleaseStgMedium` で解放 |
| CF_HDROP | 外部のブロックはヘッダ・範囲・UTF-16の配置・終端を検証してから `DragQueryFileW` に渡す。Rustのスライス長は `isize::MAX` 以下 |
| メモリの引き渡し | `SetClipboardData` / `SetData(fRelease=true)` 成功時は受け手が所有し、失敗時だけこちらで解放 |
| ファイルID | APIに合うサイズと配置の出力領域を渡し、開いたハンドルは照会失敗時も閉じる |
| Shellのコピー・移動 | STA上でCOMを使い、UTF-16名はキュー登録の呼び出し完了まで保持。操作と進捗通知のCOM参照を実行完了まで保持 |
| ウィンドウとドラッグのコールバック | 生ポインタをコールバック後へ持ち出さない。subclass用Boxは登録失敗時か `WM_NCDESTROY` で回収。効果ポインタはnull検査後に利用 |
| 監視イベント | スレッド間で待機・通知できるカーネルハンドルだけを共有し、最後の `Arc` がなくなってから閉じる |
| アイコンとバージョン情報 | 出力バッファの寸法・長さを検査し、ポインタの元になる領域を読み取り完了まで保持。取得したGDIリソースを解放 |

## 残る制約

クリップボードは、読み取り前後のシーケンス番号を比較し、変更や一時的な競合があればパス・COPY/MOVE情報・データオブジェクトを一式で取り直す（最大8回、再試行間の待機10 ms）。形式の不在だけを既定のCOPYとして扱い、取得失敗や不正なデータをCOPYへ置き換えない。遅延レンダリングでは番号の更新が遅れるため、完全なスナップショット保証ではない。また、回数と再試行間の待機は制限するが、外部COMサーバーへの個々の呼び出し時間に上限を保証するものではない。

自分で書いたファイルパスとCOPY/MOVE情報は装飾に直接使い、書き込み中に記録した番号と定期的な変更検知で外部変更を確認する。外部データの取得に失敗した間は前回の装飾を維持するが、実際の貼り付けは毎回読み取りを行い、取得失敗なら中止する。仮想Shell項目も、移動フラグと一緒に取得したデータオブジェクトを使い、装飾のキャッシュを操作に流用しない。

仕様の参照先：[GetClipboardSequenceNumber](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getclipboardsequencenumber)、[IDataObject::GetData](https://learn.microsoft.com/en-us/windows/win32/api/objidl/nf-objidl-idataobject-getdata)。

これは全 `unsafe` と依存ライブラリの完全な監査ではない。主にファイル操作、外部クリップボード、資源の寿命を対象にした点検である。

ファイルID・メタデータの再確認から実際の操作までの間に、別プロセスが対象を変更する競合は残る。複数ファイルのコピー・移動もトランザクションではなく、実行途中の失敗で一部だけ完了する場合がある。置換前データを退避して保持・復元する仕組みは、この場合のデータ消失を抑えるものであり、全件の巻き戻しを保証しない。
