# enyFile MVP（Rust + Slint）

Windows専用の2ペインファイラー。概要・インストールはルートの [README](../README.md) を参照。

## 起動・ビルド

ルートの **enyFile.cmd** で起動する。引数なしなら、プロジェクト内の試験用フォルダー `app\data\sandbox\left` と `right` を開く（初回はサンプルファイル付きで作成）。別のフォルダーは `enyFile.cmd "左のパス" "右のパス"` で指定する。

```powershell
.\app\Check.ps1            # ビルド＋単体テスト＋クリップボード連携スモーク（クリップボードを書き換える）
.\app\Check.ps1 -NoBuild
```

ツールチェーンはフォルダー内に `.tools` があればそれを使い（オフラインでビルド）、なければ PATH 上の Rust を使う。スモークのデータは `app/data/` に作成し、次回実行時に削除する。

## 操作

| 操作 | 動作 |
| --- | --- |
| Ctrl+C / Ctrl+X | 選択項目をクリップボードへ（Explorerと相互運用）。未選択なら何もしない |
| Ctrl+V | アクティブなペインの表示フォルダーへ貼り付け。同名があれば自作の確認画面。同じフォルダーなら「- コピー」で複製 |
| Delete / Shift+Delete | ごみ箱へ / 完全削除（確認はWindowsの設定に従う） |
| Enter / ダブルクリック | フォルダーを開く / 既定のアプリで開く |
| Alt+↑・Backspace / Alt+← → | 親へ / 戻る・進む |
| Tab | 左右切替 |
| Ctrl+L / F5 / Esc | パス欄 / 再読込 / 選択解除（フィルター中はフィルター解除） |
| Ctrl+F / Ctrl+G / Ctrl+Shift+G | アクティブなペインを検索（入力中にカーソルが一致項目へ移動。入力中も Ctrl+G で次へ、Enter か Esc で終了） / 次の一致 / 前の一致。検索・フィルター・フォルダー以下の検索の入力欄は、文字を消しても終わらず、空の状態で Backspace を2回押すと終了（Esc と同じ） |
| Ctrl+Shift+F | アクティブなペインをフィルター（Enterで適用、空で解除、Escで解除）。並べ替え・再読込では保たれ、別のフォルダーを開くと解除 |
| Ctrl+Alt+Shift+F | 表示中のフォルダー以下を再帰検索し、結果をアクティブなペインに表示（下の「フォルダー以下の検索」） |
| ← → / PageUp PageDown / ホイール | 前後のページへ（カーソルはページ内の同じ位置）。一覧はスクロールせず1画面ずつ表示。最初のページで ←、最後のページで → は1行ずつ移動し、ホイールはそれ以上めくらない（カーソルも動かない） |
| F2 / Ctrl+N / F7 | リネーム / 新規ファイル / 新規フォルダー（名前入力画面。リネームは拡張子以外を選択） |
| Alt+Z | アクティブなペインの隠しファイル表示を切り替え（ペインごと。既定は非表示、設定に保存。表示中は薄い文字） |
| Shift+英字 | そのドライブで最後に表示していたフォルダーへ（例: Shift+D。どのペインで表示したかは問わない。フォルダーは終了後も覚えていて、カーソル位置は起動中だけ戻す）。そのドライブを表示中ならドライブのルートへ。覚えたフォルダーが無くなっていればルートへ。存在しない文字は名前の頭文字検索 |
| Ctrl+Shift+N / S / T / E | 名前 / サイズ / 更新日時 / 拡張子で並べ替え。同じキーをもう一度で逆順 |
| Ctrl+Shift+D | ペインの比較 → もう一度で差分のみ → もう一度で終了（Esc でも終了。下の「ペインの比較」） |
| パス欄の右クリック | 「パスのコピー」「パスの編集」 |
| 右クリック | Windowsのコンテキストメニュー。空白部分ではフォルダーの背景メニュー。メニュー内の「貼り付け」「名前の変更」はアプリ側の処理（自作の確認画面・F2と同じ）を使う。フォルダーの「貼り付け」はそのフォルダーの中へ、「名前の変更」は右クリックした項目に（ドライブでは何もしない） |
| クリック・Ctrl・Shift・矢印・Ctrl+A・Space・名前のタイプ | 選択（PoCと同じ）。Shift での範囲は項目の上だけで止まり（「..」やドライブの行には入らない）、「..」から始めると先頭の項目が起点。カーソルの行の名前が省略されていると、1秒後にその行の上へ全体を表示する（隣のペインにはみ出してよい。ウィンドウの右端では左へずらす）。カーソルを動かすと消える |
| 項目のドラッグ | ブラウザ・Explorer・メールなど、ほかのアプリへドロップできる（Explorerと同じデータ。コピー・移動・ショートカットはドロップ先が決め、移動もドロップ先が行う）。選択中の項目をつかむと選択全体、未選択の項目ならその1つ。アプリへのドロップは受け付けない |

同名衝突は1件ずつ問う（NexusFile風）。その衝突に該当するボタンだけを表示し、括弧内の文字キーで選べる。Escはキャンセル、Aで「すべて適用」を切り替える。
フォルダーの「結合」は中の衝突も1件ずつ問う。「フォルダの置換」は既存のフォルダーを同じ場所で「名前~enyfile-old」に退避してから貼り付け、成功したらごみ箱を経由せずに削除する。失敗や中止のときは元の名前に戻す（新しい側が既にその名前を使っていれば両方を残し、メッセージで知らせる）。
コピー元が既存のフォルダーの中にあっても置換できる（`Folder\Folder` を `Folder` の隣に貼り付けて中身を一段上げる、など）。退避した側から貼り付ける。
貼り付ける項目が貼り付け先に既にある同じもの（ハードリンクやジャンクション経由を含む）のときは質問しない。コピーは「名前 (2)」として複製し、移動は何もしない。フォルダーをそれ自身やその中へ貼り付けようとした項目は、質問の前にスキップする。
実行の直前にも、置換するフォルダーが確認時と同じものか、貼り付け元そのものでないかを確かめ、合わなければ何も変更せずに中止する。
リネームでは名前欄で Enter が決定、Esc が戻る。キャンセルするとファイルは何も変わらない。
表示中のフォルダーは監視しており、Explorer等での変更は自動で反映する。

## 画面（NexusFile風）

暗い配色、メニュー（ファイル / 編集 / 表示）、ツールバー、2ペイン、最下部の履歴行（操作結果やエラー。将来ダブルクリックでAIへの入力にする予定）。

- ツールバー: 戻る・進む・親へ（◁ ▷ △）、ホーム（アクティブなペインで起動時のフォルダーを開く。設定の「起動時の左 / 右」、3・4番目のペインは左 / 右と同じ）、デスクトップ・ドキュメント・画像・動画・音楽（アクティブなペインで開く）、ブックマーク
- ブックマーク: クリックでプルダウン。項目クリックで移動、✎で編集画面（名前・パス・上へ／下へ・削除）、「＋ 現在のフォルダを追加」
- 設定画面: ファイル > 設定...。タブは4つ
  - パス: 5つの場所（デスクトップ・ドキュメント・画像・動画・音楽）のパスを入力または「参照...」で選ぶ。空欄（既定に戻す）はWindowsの既定フォルダー（OneDriveへのリダイレクトも反映）で、そのパスを薄く表示する
  - パス（起動時の左・右）: 引数なしで起動したときに開くフォルダー。空欄は開発用の試験フォルダー
  - カラー: 基本カラー（背景・前景・フォルダ・ドライブ・読み取り専用・隠し・サイズ・日付・属性・種類・選択・カーソルなど）と拡張子の色分け。項目のダブルクリックで色編集（RGB）。拡張子の色分けは追加・編集・削除・既定に戻す。名前と拡張子の列が色分けされる
  - 表示: ウィンドウの不透明度（30〜100%）、フォント名とサイズ（行の高さもサイズに合わせる）
  - その他: フォルダー以下の検索でジャンクションとシンボリックリンクの先も検索するか（既定はオフ）
  - 保存ボタンで反映して設定ファイルへ保存、Escまたはキャンセルで破棄
- 中央の仕切り: ドラッグで左右の幅を変更、ダブルクリックで半分ずつ。位置は保存され次回も同じ
- `..` 行: クリック・↑（先頭の項目から）・Homeでカーソルが乗る。Enter / ダブルクリックで親へ。空のフォルダーではここにカーソルがある
- 設定ファイル: 開発中は `app\data\config.json`（exeが `app\target` 以外にあるときは exe と同じフォルダーの `config.json`）。場所・ブックマーク・仕切り位置・終了時のウィンドウ位置とサイズ（最大化状態を含む）をアプリが保存する。知らないキーは保存時もそのまま残す

```json
{
  "places": { "desktop": "D:\\Desk", "pictures": "D:\\Pic", "videos": "D:\\Video", "music": "D:\\Music" },
  "bookmarks": [ { "name": "作業", "path": "D:\\Work" } ],
  "split": 0.5
}
```

- ペイン上部はパンくず形式のパス。区切りをクリックするとそのフォルダーへ移動する。空白部分のクリックまたはCtrl+Lで入力欄になる。右端の↺で再読込
- その下に「フォルダ数・ファイル数・合計サイズ」（選択中は選択数）と「ボリューム名・空き容量」
- 一覧は見出し行なし。`..` 行（ダブルクリックで親へ）、アイコン・名前・拡張子・サイズ・日付（今日 / N 日以前 / 年月日）・時刻・属性（A R H S）・種類
- アイコンはWindowsが表示するもの（関連付けアプリのアイコン）。exe・ショートカット等の個別アイコンは一覧表示の後から差し替える
- 一覧の下にドライブ一覧（名前・使用量バー・空き容量）。カーソルを乗せられ、Enter / ダブルクリックでそのドライブへ。5秒ごとに裏で更新
- 並べ替えは「表示」メニュー（名前・サイズ・更新日時・拡張子）。同じ項目をもう一度選ぶと昇順・降順が切り替わる
- 表示メニュー: 隠しファイル（アクティブなペイン）の表示、列（サイズ・日付・時刻・属性・種類）ごとの表示切り替え、ペイン数の切り替え。設定に保存
  - 2 ペイン（Ctrl+Shift+2）: 左右。中央の仕切りで幅を変更
  - 3 ペイン（Ctrl+Shift+3）: 1回目は縦長を横に3列、3ペイン中にもう一度で横長を縦に3段。交互に切り替わる
  - 4 ペイン（Ctrl+Shift+4）: 2×2
  - どのレイアウトもペイン間の仕切りをドラッグして大きさを変えられる（4ペインは縦横1本ずつ）。ダブルクリックで均等。位置はレイアウトごとに保存
  - 狭いペインではパンくずを末尾から表示し、ドライブの使用量バーと情報行のボリューム名を省く
  - 3・4ペインの列は名前（拡張子込み）・サイズ・時刻のみ（列の表示切り替えも効く）。Tabは表示中のペインを順に巡回
- 編集メニュー: コピー・貼り付け・削除・絶対パスのコピー・ファイル名のコピー（選択項目を1行ずつ。未選択ならカーソル行）・同じ拡張子をすべて選択・検索・フィルター
- 検索・フィルターの文字: `*` と `?` のワイルドカード（名前全体に一致）。ワイルドカードなしは部分一致。`;` で複数指定。大文字小文字は区別しない
- フォルダー以下の検索（Ctrl+Alt+Shift+F、編集メニューにもあり）
  - 検索バーを開いた時点で裏でフォルダー以下の走査を始め、名前・サイズ・日時・属性だけをメモリに持つ（1 件あたり 100〜150 バイト程度）。入力が 120ms 止まるたびに、ディスクを読み直さずにその一覧から絞り込む。Enter で確定（バーを閉じて結果を残す）、Esc でやめて元のフォルダーへ
  - 項目が 1,000,000 件を超えるツリーはメモリに持たず、入力中の絞り込みをやめる。その場合は Enter のたびにディスクを走査する
  - 見つかった順に結果を表示する（浅いフォルダーから）。照合の完了後に、現在の並べ替え順で並べ直す。文字を変えても、新しい結果が届くまで前の結果を表示したままにする。結果は最大 100,000 件
  - 名前の前に、検索したフォルダーからの相対フォルダーを薄く表示する。名前順の並べ替えは相対パス順になる
  - `/` または `\` を含む文字はフォルダー部分も含めて照合する。`src/*.rs` はどの階層の src でも一致し、`\src\*.rs` は検索したフォルダー直下の src だけに一致する
  - Esc・Backspace・`..` で結果を閉じて元のフォルダー表示（カーソル位置も元どおり）に戻る。F5 で走査し直して同じ条件で再検索。別のフォルダーへの移動や結果を閉じる操作は走査を止めてメモリを解放し、文字の変更は実行中の照合を中断する
  - 結果の中では開く・コピー・切り取り・削除・リネーム・フィルターが使える。貼り付けと新規作成は使えない。結果はその時点のもので、自動では更新しない
  - ジャンクションやシンボリックリンクのフォルダーは、既定では結果に出すだけで中に入らない（循環参照や、意図しない巨大な範囲の走査を避けるため）。ファイル > 設定 > その他 の「ジャンクションとシンボリックリンクの先も検索する」で入るようにできる（既定はオフ）。その場合も、走査済みの範囲を指すリンクには入らない。開発ビルドでは `app\data\sandbox\left\リンクの例` で違いを試せる（中の「説明.txt」を参照）
  - 隠しファイルの表示設定（Alt+Z）に従う。読めないフォルダーは飛ばす
- ペインの比較（Ctrl+Shift+D、表示メニューにもあり）
  - アクティブなペインと、その前にアクティブだったペインの今のフォルダーを、名前で行を揃えて並べる。番号の小さいペイン（左・上）を旧、もう一方を新とみなす。フォルダーの中身までは比較しない
  - 旧にだけある項目は赤い背景と `-`、新にだけある項目は緑の背景と `+`。相手側の同じ行は空行になる
  - 両方にあって違う項目は、違うセルだけを黄色の背景にする（サイズ、日付と時刻、属性）。日時は 2 秒までの差を同じとみなす（FAT 系ドライブの精度のため）。フォルダーは日時と属性を比較する
  - もう一度 Ctrl+Shift+D で同じ行を隠して差分だけにする。3 回目か Esc で終了し、元の一覧と並べ替え順に戻る
  - 比較中は両ペインとも名前順で、カーソルとページは左右で連動する（空行にもカーソルが乗る）。コピー・貼り付け・削除はそのまま使え、フォルダーが変わると自動で比較し直す
  - 比較中は並べ替え・フィルター・フォルダー以下の検索は使えない。どちらかのペインで別のフォルダーを開くと比較を終了する
  - 色は設定画面のカラーで変えられる
- メニューバーはメニューを開いたまま横へマウスを動かすと隣のメニューに切り替わる（← → でも切替、Esc か外側クリックで閉じる）
- 色はすべて `ui.slint` の `Theme` で定義している（テーマ切り替えの準備）

## 構成

- `src/main.rs` UIスレッドの制御。各ペインの一覧ワーカー、結果は `invoke_from_event_loop` で受け取る
- `src/listing.rs` 列挙・自然順ソート・選択モデル
- `src/paste.rs` 貼り付けの計画（1件ずつの質問、再帰結合、別名と検証）
- `src/shell.rs` クリップボード、IFileOperation、既定アプリ起動、フォルダー監視
- `src/ui.slint` 画面と衝突の確認画面
- `src/smoke.rs`、`src/bin/shellprobe.rs` 自動検証用（Explorer役）
