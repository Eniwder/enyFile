## ファイル操作の習慣

- サンドボックスでは Windows 標準のごみ箱を使わない。ごみ箱を指定した API でも、エラーなく完全削除されることがある。
- 完全削除は、ユーザーが明示的に指示した場合だけ実行する。
- 単に「削除して」と頼まれたら、完全削除になることを伝えて許可を求めるか、書き込み許可範囲内の別フォルダへの退避を提案する。退避は同意を得てから行い、復元できるよう元のディレクトリ構造を保つ。
- 作業フォルダがドライブのルートやユーザーフォルダなど広すぎる場合は、変更する前に何をするかを伝えて確認を取る
